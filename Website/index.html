Current focus

Basis compatibility

The port automatically uses its Basis shim when Basis/Vixxy are installed and the VRChat SDK is absent. Armature Link and Blendshape Optimizer are supported priorities. SPS remains deferred.

Manual installation

VPM CLI

Add the registry with:

vpm add repo https://vpm.toysland.pw/index.json

Then install com.toys0125.vrcfury-basis from your VPM-compatible package manager.
